Elysium Pizza — Extensive Administrator & Developer API Documentation

This documentation is strictly invisible to customers and only accessible within an authenticated Admin session. It covers Netlify deployment, NeonDB PostgreSQL setup, environment variables, and CORS-enabled REST APIs for external developers.

1. Netlify Environment Variables & NeonDB Setup

In your Netlify Dashboard → Site Configuration → Environment Variables, configure the following three variables. The serverless function (netlify/functions/api.js) reads these variables automatically at runtime and auto-creates all required PostgreSQL tables on first invocation:

Environment Variable Purpose Example Value
DATABASE_URL / EP_DATABASE_URL NeonDB Serverless PostgreSQL connection URI (creates conflict-free ep_* tables & ep_vw_* views) postgresql://user:pass@ep-xyz.us-east-2.aws.neon.tech/elysium?sslmode=require
ADMIN_USERNAME / EP_ADMIN_USERNAME Administrator login username & write-API header credential elysium_admin
ADMIN_PASSWORD / EP_ADMIN_PASSWORD Administrator login password & write-API header credential Elysium@2026

2. Public & Protected CORS-Enabled REST API Endpoints

All endpoints under /api/* (routed via netlify.toml to /.netlify/functions/api/:splat) include permissive CORS headers so external developers, mobile apps, and partner aggregators can consume live menu, blog, order, and festive data from any origin: 

Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS
Access-Control-Allow-Headers: Content-Type, Authorization, X-Admin-Username, X-Admin-Password
Content-Type: application/json; charset=utf-8
HTTP Method & Endpoint Access Level Description & Payload
GET /api/menu Public (CORS *) Returns all pizza, melt, pasta, side & dessert items from NeonDB (`ep_menu_items` & `ep_vw_active_menu_catalog`).
POST /api/menu Admin Auth Creates or upserts a dish (`name`, `category`, `price`, `calories`, `is_veg`, `description`).
PUT /api/menu/:id Admin Auth Updates an existing pizza/food item by ID.
DELETE /api/menu/:id Admin Auth Permanently removes a dish from the NeonDB catalog.
GET / POST /api/orders Public / Admin Places a new customer order (`POST`) or retrieves orders (`GET`). `PUT /api/orders/:id` updates live oven status.
GET / POST / PUT / DELETE /api/blogs Public GET / Admin Write Full CRUD for *The Elysium Journal* blog posts.
GET / POST / DELETE /api/testimonials Public GET & POST / Admin Delete Fetch verified guest reviews, submit new diner reviews, or moderate reviews.
GET / POST / PUT / DELETE /api/contacts Public POST / Admin Read & Write Submit customer catering/contact inquiries (`POST`) or manage status in Admin CRM.
GET / PUT /api/settings Public GET / Admin PUT Reads or updates active festive theme (`diwali`, `holi`, `christmas`, `eid`), banner copy & discount rate.

3. Sample External Developer Fetch Snippet (CORS Enabled)

// Any external developer can query the public menu API:
const res = await fetch("https://your-site.netlify.app/api/menu");
const { data, count } = await res.json();

// Authenticated Admin Write Request (POST / PUT / DELETE):
await fetch("https://your-site.netlify.app/api/menu", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Admin-Username": "elysium_admin",
    "X-Admin-Password": "YOUR_ADMIN_PASSWORD"
  },
  body: JSON.stringify({
    name: "Diwali Saffron Pistachio Burrata Pie",
    category: "Gourmet Specials",
    price: 679,
    is_veg: true,
    description: "Limited festive creation."
  })
});
